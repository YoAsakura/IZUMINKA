ИЗЮМИНКА

Положите эти четыре файла рядом с index.html:
- nazad.mp3
- stop.mp3
- gaz.mp3
- alga.mp3

Откройте index.html в браузере.

Логика:
- ивент: 2–10 секунд;
- после ивента проигрывается alga.mp3;
- после завершения ивента запускается пауза 15 секунд–3 минуты;
- одновременно активен только один ивент;
- кнопка запускает/ставит цикл на паузу;
- общий таймер слева показывает всё время работы приложения;
- таймер справа показывает время, прошедшее с последнего завершения ивента (момента запуска alga.mp3);
- после каждого нового alga правый таймер сбрасывается на 00:00.
